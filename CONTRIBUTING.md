# Contributing

Thanks for wanting to help.

## Reporting

- **`brew install --cask danieldeusing/tap/configr` fails:** open an issue here with
  the full output and `brew config`.
- **A problem inside Configr:** open an issue in
  [configr-releases](https://github.com/danieldeusing/configr-releases/issues).

## Changing the code

`Casks/configr.rb` is written by Configr's release workflow with every release, so
a pull request that edits it is overwritten by the next release. Describe the
problem in an issue instead, and the fix goes into the release workflow.
